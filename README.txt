마지막 상영회: 20시42분 | 은하극장 인게임 리셋 v6

스토리·인물 설정·증거 원문·투표·엔딩은 그대로입니다.
맵/캐릭터/인게임 조작과 오프닝 재생을 수정했습니다.

새 인게임
- 기존 타일맵 엔진·배경 이미지·누적 덮어쓰기 코드를 제거했습니다.
- assets/game/cinema.js 하나가 새 지도·캐릭터·충돌·수첩을 담당합니다.
- 로비, 매표소, 상영관 입구, 관리사무실, 영사실, 기록보관실,
  지하 설비창고, 정비 작업실의 8개 공간을 출입문으로 연결합니다.
- 기본 확대 2× / 전체 보기 / 확대 3×를 상단 버튼으로 전환합니다.
- 방향키·WASD 또는 화면 방향 버튼 이동, 조사 A/Enter/Space,
  수첩 B, 안내도에서 출입문 방향 표시를 사용할 수 있습니다.
- 캐릭터는 타일 기준 1칸 폭·1.5칸 높이의 표시 영역으로 통일했습니다.
- 예전 맵의 위치는 새 로비로 복원하고 수집한 증거와 조사권 사용은 유지합니다.
- 관리사무실은 2차 수색부터, 개인 소지품도 2차부터 열람합니다.
- 관리자는 시찰만 하며 증거를 가져가지 않습니다.

오프닝
- 관리자에서 '오프닝' 단계를 시작하면 영상이 바로 나타나 무음 재생됩니다.
- 참가자에게 단계가 전달되면 같은 영상이 자동으로 나타납니다.
- 소리는 '소리 켜기'를 누릅니다. 원격 기기의 소리 자동재생은 브라우저가
  제한하므로 무음으로 먼저 시작합니다.
- 약197초 스토리·음성을 유지한 H264/AAC MP4 약9MiB입니다.
- '눌러서 오프닝 재생'만 표시하던 이전 화면을 제거했습니다.
- 파일이 없거나 재생할 수 없으면 경로와 원인을 표시하고 재시도합니다.
- 오프닝 종료로 자동 다음 단계 진행/개표는 하지 않습니다.
