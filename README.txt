구성
- 참가자4명 + 관리인 문서윤(진행자)1명. 총5명 고정입니다.
- 윤서현(감독), 박재민(영사·음향), 한지우(운영PD), 권시우(배급·계약).
- 현장 증거18개: 1차9개(C01~C09), 2차9개(C10~C18).
- 공범이 없으므로 공범 채팅·다중 지목·범인 수 예측은 사용하지 않습니다.
- 개인 소지품 열람은2차부터 가능하며 원래 주인에게 남습니다.

파일 실행
1. 압축을 모두 풀고 index.html을 열면 한 기기 오프라인 시연으로 시작합니다.
   지도·캐릭터·영상은 assets 폴더를 함께 유지해야 합니다.
2. 관리자 비밀번호: lastscreening2026
3. 관리자는 문서윤으로 입장하며, 오프라인 콘솔에서 원하는 배역을 지정해 시연할 수 있습니다.
4. 오프닝은197초, 세로1080×1920입니다. 재생 버튼·건너뛰기·다시보기를 제공합니다.
   영상 자체에 자막이 들어 있습니다. 보조VTT 자막은 기본으로 꺼 두었습니다.
5. 기본 진행 시간은 설정집12분 + 오프닝4분 +1차수색20분 +토론10분
   +2차수색20분 +최종토론18분 +투표6분 =90분 +엔딩입니다.
   진행자가 시간과 단계를 직접 조정할 수 있으며 영상 종료로 자동 개표하지 않습니다.

여러 휴대폰으로 진행
1. 이 폴더 전체를 기존 청명산장과 다른 게시 폴더/주소에 올립니다.
2. 기존 Firebase 연결 설정을 유지하되 이 작품은 다음 별도 경로만 사용합니다.
   /games/last-screening-2042/rooms/default
   이전 /rooms/main 및 /rooms/last-screening-4와 분리됩니다.
3. firebase-rules-merge.json은 새 경로에 추가할 규칙 예시입니다.
   기존 rules를 통째로 덮지 말고 games/last-screening-2042 항목을 병합합니다.
   이미 games 규칙을 사용하는 경우 그 안에 해당 작품 항목을 추가합니다.
   예시 규칙의 접속 유효기간은 기존 자료와 같은2027년1월1일00:00(한국시간) 전까지입니다.
4. 참가자는 이름·성별 등록 후 대기하고 관리자가 역할을 일괄 배정합니다.
   최대4명에게 중복 없이 무작위 배정되며 관리자 슬롯은 별도입니다.
5. 관리자가 단계를 시작하면 타이머·수색 단계·증거 선점·DM·투표·판정·엔딩을 공유합니다.
6. ?offline=1은 서버에 접속하지 않는 한 기기 시연입니다.

투표와 점수
- 참가자는 한 명만 선택해 제출하며 제출 후에는 바꿀 수 없습니다.
- 유일한 최다득표자를 최종 지목합니다. 2-1-1이면2표 후보가 지목됩니다.
- 최다득표 동률이면 해당 후보로 결선 투표1회. 재동률이면 지목 실패 엔딩입니다.
- 비범인: 정확 지목+5 / 오지목−2 / 개인 목표 각1점, 최대3점.
  설정집 목표1의 진범 지목1점은 개인 투표로 자동 계산합니다.
- 범인: 최종 검거 회피+5 / 정산자료 은닉 미적발+2 / 알리바이 방어+1.
  검거 회피는 최종 지목 결과를 따릅니다. 과반수 여부를 별도 보상으로 중복 판정하지 않습니다.
- 관리자 콘솔에서 계약금 문제 규명과 사적 목표를 확인한 뒤 엔딩을 공개합니다.
  판정은 공개 때 고정되고 종료 뒤에는 변경되지 않습니다.

맵
- 제공된 층별 원본 그림3장을 사용합니다. 캐릭터는 방향키/WASD/조이스틱으로 이동합니다.
- 실제 벽·가구 충돌, 계단과 조사 오브젝트를 그림에 맞춰 지정했습니다.
- 1층 우측 관리사무실 내부는2차수색부터 열립니다.
- 2층 홍보키트2번은 기록보관실 동쪽 선반에서 조사합니다.
- 물건은 현장에 남고 최초 조사자만 디지털 증거카드를 획득합니다.
  다른 참가자는 같은 장소에서 조사 완료 안내만 봅니다.
